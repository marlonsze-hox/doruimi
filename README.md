# 施秉睿的中文简历网页

北京求职方向：数据分析助理、统计分析、市场研究。

纯静态网页，包含手机适配、邮箱联系、复制邮箱和打印样式。直接打开 `index.html` 即可浏览。无需安装软件或构建。

## GitHub Pages 发布

网页文件应位于 `marlonsze-hox/doruimi` 仓库的 `main` 分支根目录。

1. 打开 [仓库的 Pages 设置](https://github.com/marlonsze-hox/doruimi/settings/pages)。
2. 在 **Build and deployment** 的 **Source** 中选择 **Deploy from a branch**。
3. 选择 **main** 分支及 **/(root)**，点击 **Save**。
4. 等待 GitHub 显示发布成功后，访问 `https://marlonsze-hox.github.io/doruimi/`。

上方网址是此仓库的预期发布地址，保存文件本身不代表 Pages 已启用或网址已经上线。

官方说明：[配置 GitHub Pages 发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
